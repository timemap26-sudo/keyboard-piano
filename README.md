# 🎹 鍵盤鋼琴 Keyboard Piano

用電腦鍵盤當鋼琴琴鍵的網頁遊戲。

**線上遊玩：** https://timemap26-sudo.github.io/keyboard-piano/

## 功能
- 兩排鍵盤共 32 個琴鍵（C3 – G5），可用 ← / → 切換八度
- 四種音色：平台鋼琴、電鋼琴、管風琴、8-bit，全部以 Web Audio 即時合成
- 空白鍵延音踏板、殘響開關、音量調整
- 錄音與播放
- 落下音符遊戲：演奏挑戰（計分、連擊、評等）、練習模式（等你按對）、自動示範
- 支援滑鼠與觸控（可滑奏）

## 按鍵對照
| 排 | 白鍵 | 黑鍵 | 音域 |
|---|---|---|---|
| 下排 | `Z X C V B N M , . /` | `S D G H J L ;` | C3 – E4 |
| 上排 | `Q W E R T Y U I O P [ ]` | `2 3 5 6 7 9 0 =` | C4 – G5 |

按 `Enter` 開始遊戲、`Esc` 停止。

## 本機執行
直接用瀏覽器開啟 `index.html` 即可，不需安裝任何套件。
